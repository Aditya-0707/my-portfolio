Overview

Decoding Complex Rule-Driven APIs

CalcInsight is a web-based observability and debugging platform built to decode and analyze complex rule-driven insurance calculation APIs powered by Newgen's BRMS. It transforms deeply nested, computation-heavy JSON payloads into structured, human-readable intelligence — enabling rapid diagnosis of underwriting, financial risk, and multi-policy calculation scenarios.

How It Works

End-to-End Diagnostic Pipeline

CalcInsight follows a structured, multi-stage pipeline that transforms a raw API request into clear, actionable debugging intelligence.

01

API Request Input

User submits a complex BRMS JSON payload or triggers a live API call via the built-in simulation layer.

02

L1 Pre-Validation

The JSON passes through the L1 validation layer, catching structural errors and missing fields before deeper analysis.

03

JSON Decomposition

Deeply nested payloads are intelligently parsed and mapped to business entities — policies, riders, risk factors, and financial layers.

04

Rule-Aligned Visualization

Decomposed data is rendered into structured tables and visual flows, aligned with BRMS rule logic for clear interpretation.

05

AI-Augmented Analysis

AI-assisted mapping correlates inputs with rule outcomes, automatically flagging anomalies and calculation mismatches.

06

Actionable Insights

Precise root cause identification enables resolution in under 10 minutes — down from hours of manual debugging.

The Challenge

Dense Logic, Slow Diagnosis

The underlying calculation engine operated on extremely dense and interdependent rule logic, creating a critical bottleneck in debugging workflows.

⚙️

Multi-Policy Complexity

Multiple policy types — current, rider, existing, IIB, simultaneous — processed in a single request, creating deeply interdependent data.

🔗

Coupled Calculations

Financial and medical risk calculations were tightly coupled, making isolated debugging nearly impossible.

📦

Payload Scale

JSON payloads scaled significantly in size and complexity, requiring manual decomposition for any form of analysis.

🐌

Slow RCA Cycles

Root cause analysis lacked transparency, and resolution cycles were inconsistent and painfully slow.

~3 hrs
Average Resolution Time
Often extending to a full working day
The Solution

A Rule-Aware Debugging Layer

CalcInsight bridges the gap between raw API data and business logic interpretation, introducing five core capabilities.

01
🧩

Intelligent JSON Decomposition

Transforms complex, array-heavy payloads into contextual, structured datasets mapped to business entities and policy layers.

02
📊

Rule-Aligned Visualization Engine

Dynamically presents calculation flows, risk parameters, and derived values in clean tabular and visual formats aligned with underlying rule logic.

03
🚀

Real-Time API Simulation Layer

Enables live request-response execution via a lightweight web interface powered by Google Apps Script — a Postman-equivalent built into the platform.

04
🧠

AI-Augmented Interpretation

Incorporates AI-assisted mapping to correlate inputs with rule outcomes, improving accuracy in identifying calculation anomalies.

05
🔄

Multi-Stage Debugging Workflow

Seamlessly integrates with a prior JSON validation layer (L1), enabling a progressive L1 → L2 diagnostic pipeline.
